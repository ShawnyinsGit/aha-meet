# RK3588 / RK3576 Linux 手持终端 ODM 与样机采购调研

> 调研日期：2025 年（本轮网络检索执行日）。
> 需求画像：手机形态（6–7 寸屏、可加厚放大电池、反向充电、侧边按键、无键盘）、跑 Ubuntu/Debian、5G 数据模组（Quectel RM500Q/RM520N 类）、先用工厂现有样机/公模机做 demo，后续再定制（改壳、改电池、改按键）。
> 数据来源：公开网页检索（厂商官网、1688/淘宝/京东商品页、行业文章）。所有价格均为网页快照价格，实际需向厂商询价确认；查不到的信息标注"未验证"。

## 0. 结论先行

- **市面上几乎没有现成的"6–7 寸手机形态 + RK3588"整机**。RK3588 整机的主流形态是 **8–10.1 寸三防平板**（工业 PDA 多用低端芯片如 MT6765/RK3562）。最接近需求、且明确支持 Ubuntu/Debian 的现货整机是：**亿道 EM-R16（10.1 寸，RK3588，官方有 Ubuntu 22.04 / Debian 11 版本）** 和 **辰想 CX10A（10.1 寸，RK3588，宣传支持 Linux/Ubuntu/麒麟，淘宝 ¥2899 起）**。
- **"直接买样机做 demo"最快路径**：淘宝/1688 现货买 1–2 台 RK3588 Ubuntu 三防平板（辰想 CX10A 或亿道 EM-R16 Ubuntu 版），一周内到货即可做软件 demo；5G 通过 M.2/USB 模组扩展（多数三防平板有 4G/5G 选配或 M.2 槽，需下单前与卖家确认 RM500Q/RM520N 兼容性）。
- **手机形态（6–7 寸）需要定制**：现有公模手机形态 PDA 几乎都不是 RK3588，若坚持 6–7 寸，现实路线是「开发板 + 屏幕 + 电池」自组 demo 验证，再找 ODM 开模定制整机。

## 2. "直接买样机做 demo"的最快 3 条路径（排序）

### 🥇 路径 1：淘宝现货买 1–2 台"RK3588 + Ubuntu"三防平板（1 周内可跑 demo）

- **买什么**：辰想 CX10A（¥2899 起，标题明示 Ubuntu）或亿道 EM-R16 Ubuntu 版（经销商约 ¥7300，官方支持最靠谱）。
- **怎么做**：下单前与卖家确认三点——① 是否可预装/提供 Ubuntu 或 Debian 镜像及刷机包；② 是否有 4G/5G 选配（M.2 B-key + SIM），能否兼容 Quectel RM500Q/RM520N（RM520N 是 M.2 接口，三防平板若有 M.2 5G 选配通常就是此类模组）；③ 是否提供内核源码/设备树（后续定制必需）。
- **代价**：10.1 寸而非手机形态；电池 5000–10000mAh 不可随意加大；无反向充电/侧键自定义（需 demo 阶段接受妥协或用软件模拟）。
- **时间**：3–7 天到货。

### 🥈 路径 2：Firefly / ArmSoM 开发板 + 官方触摸屏 + 充电宝（3 天内可验证软件栈）

- **买什么**：ROC-RK3588S-PC + 10.1 寸 MIPI 触摸屏套餐（京东），或 ArmSoM Sige7 / Sige5（RK3576 验证）。
- **怎么做**：官方 Ubuntu/Debian 镜像开箱即用；5G 用 M.2 转接板 + RM500Q/RM520N + USB 供电自组；移动性靠 PD 充电宝（顺便可验证"反向充电"场景的供电链路）。
- **代价**：完全没有产品形态，只适合内部/技术向 demo。
- **时间**：京东 1–3 天；Linux 适配工作量全平台最低。

### 🥉 路径 3：直接联系亿道/前海高乐/ScenSmart 洽谈"公模机 + Linux + 5G 模组"小批量样机（2–4 周）

- **怎么做**：以"行业客户"身份询价，要求：公模三防平板 + Ubuntu/Debian 固件 + 内置 RM520N 5G 模组 + 去掉不需要的模块（扫码头等可减配）。厂商对"现有公模 + 软件定制"通常 MOQ 很低甚至可卖 1–5 台工程样机（单价上浮）。
- **价值**：这一步同时完成了"未来定制量产"的供应商尽调——同一家厂既能给样机也能接后续改壳/改电池/改按键订单，避免换供应商的迁移成本。
- **时间**：沟通 + 出样 2–4 周。

**推荐组合**：路径 1 和路径 2 立即并行下单（总成本 < ¥10k，一周内软件 demo 可跑），同时启动路径 3 的商务接触。

## 3. 定制化的成本 / 周期现实预期

> 以下数字来自公开行业文章与厂商 ODM 页面，仅作量级参考，具体以厂商报价为准。

| 阶段 | 典型内容 | 成本量级 | 周期 | 来源 |
|---|---|---|---|---|
| **公模贴牌/轻定制**（改 Logo、预装软件、换系统镜像） | 不改结构 | MOQ 可低至几十–500 台；单价在现货价上加 10–30% | 2–4 周 | CSDN 行业文（2025-11）：公模标准配置 MOQ 可低至 500 台 |
| **中度定制**（改电池容量、加减功能模块、改按键、改接口） | 不动主结构模具，改 PCB 局部 + 结构件 | MOQ 通常 500–2000 台；NRE 费用数万–十几万元（未验证具体报价） | 1.5–3 个月 | 深蓝宇 ODM 页：基于核心模块定制整机 45–90 个自然日交样机 |
| **深度定制**（全新 6–7 寸手机形态 ID、开模、5G 模组内置、反向充电电路） | ID 设计 + 结构开模 + PCB 重布 + 认证 | 开模定制 MOQ 普遍 1000 台以上；复杂三防结构 2000 台以上；模具费 + NRE 通常数十万–百万元量级（行业惯例，本轮未获得厂商书面报价，标注未验证） | 4–8 个月（含 EVT/DVT/PVT、可靠性测试、3C/SRRC/CTA 认证） | CSDN 行业文（2025-11）：开模定制外观 MOQ 提高到 1000 台以上，工业三防设计往往 2000 台以上 |
| **5G 模组集成** | RM500Q（M.2，~¥700–1000/片量级）/ RM520N（M.2）内置 + 天线设计 + 认证 | 模组物料成本外，天线调试与 SRRC/CTA 入网认证是主要隐性成本（数万–数十万元，未验证） | 含在整机定制周期内 | 行业常识推断 + Quectel 公开规格；具体报价未验证 |

**现实预期建议**：

1. **不要指望找到现成的"RK3588 手机形态公模机"**——本轮检索确认该形态在 1688/淘宝/厂商官网均不存在，它是需要定制开模的产品。
2. **6–7 寸化的可行替代**：8 寸三防平板是最小现成形态（辰想/高通电子均有 8 寸机型）；若坚持 6–7 寸，多数厂会建议用其手机形态公模（但那些公模不是 RK3588，需换芯重布板，等同深度定制）。
3. **Linux 不是问题**：瑞芯微官方 SDK 自带 Buildroot/Debian，亿道/辰想/高乐均有 Ubuntu 出货先例；谈定制时把"提供内核源码 + 设备树 + 刷机工具链"写进合同即可。
4. **反向充电**：三防平板普遍支持 OTG 供电输出，但"大电池对外快充（如 18W PD 输出）"需要定制电源管理电路，属中度定制项，需在需求阶段明确提出。
5. **供应商策略**：优先选**既有 RK3588 Ubuntu 现货整机、又接 ODM 定制**的厂商（亿道、辰想、前海高乐），样机阶段和量产阶段同一家，迁移成本最低。
